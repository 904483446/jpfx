# V0.4 竞品分析任务与报告 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有空间和 RAG 数据基础上交付可追溯、可导出的真实竞品分析闭环。

**Architecture:** 新增模型配置、分析任务/候选/证据/报告模型；所有读取以 `user_id + space_id` 为边界。固定服务流水线先收集公开证据和私有 RAG 片段，再调用用户的 DeepSeek Key 生成报告 JSON；FastAPI `BackgroundTasks` 执行，浏览器以轮询呈现状态。

**Tech Stack:** FastAPI、SQLAlchemy、Alembic、PostgreSQL/pgvector、httpx、cryptography、reportlab、python-docx、Next.js、React、TypeScript、Vitest。
