# V0.2 空间内文档管理 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在当前用户自己的产品空间内实现 Cookie 会话保护的单文件上传、文档列表和删除，并将空间详情页升级为文档管理页。

**Architecture:** 后端新增 Document 元数据模型、复合所有权外键、本地存储适配器和文档服务；路由只处理 multipart 输入、当前用户依赖和响应转换。前端新增 documents API helper 和客户端组件，继续复用 apiRequest 的 credentials include 语义。V0.2 只创建 uploaded 文档，不实现解析、索引或 reindex。

**Tech Stack:** FastAPI、SQLAlchemy、Alembic、Pydantic、pytest、PostgreSQL、Next.js、React、TypeScript、Vitest、Testing Library。
