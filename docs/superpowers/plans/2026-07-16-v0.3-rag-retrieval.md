# V0.3 RAG 检索 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为空间文档提供四格式同步索引和严格隔离的 pgvector RAG 检索。

**Architecture:** 文档索引路由只做认证与输入转换；解析、切分、DashScope embedding、chunk 持久化由独立服务完成。每次索引在同一用户和空间边界内替换该文档旧 chunks；检索同时过滤 user_id 与 space_id。

**Tech Stack:** FastAPI、SQLAlchemy、Alembic、PostgreSQL/pgvector、DashScope、pypdf、python-docx、Next.js、Vitest。

---

## 文件结构

- `services/api/app/models/document_chunk.py`：chunk ORM 与复合隔离约束。
- `services/api/app/services/document_parser.py`：PDF/DOCX/TXT/MD 提取与清洗。
- `services/api/app/services/text_chunker.py`：确定性窗口切分。
- `services/api/app/services/embedding_provider.py`：DashScope 请求与密钥缺失错误。
- `services/api/app/services/retrieval_service.py`：索引、重试、检索与状态流转。
- `services/api/app/api/v1/retrieval.py`、`documents.py`：认证 API。
- `apps/web/lib/retrieval.ts`、`components/app/space-retrieval.tsx`：检索调用与界面。
